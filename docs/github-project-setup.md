# Настройка GitHub Projects

## Типы задач

- Feature - новая пользовательская функция
- Task - техническая или организационная работа
- Bug - дефект
- Research - уточнение требований или проверка гипотезы
- Test - проверка качества
- Docs - документация

## Статусы

- Backlog - задача записана, но еще не готова к выполнению
- Ready - требования понятны, задачу можно брать в работу
- In Progress - задача выполняется
- Review - результат проверяется по требованиям
- Test - идет тестирование
- Done - результат принят

Лимит WIP для In Progress: одна задача.

## Кастомные поля

| Поле | Значения |
| --- | --- |
| Priority | P0 Critical, P1 High, P2 Medium, P3 Low |
| Type | Feature, Task, Bug, Research, Test, Docs |
| Size | XS, S, M, L |
| Release | MVP, Later |
| Target date | Плановая дата завершения |

## Представления

1. `Board` - группировка по Status, основной вид ежедневной работы.
2. `MVP Table` - таблица с фильтром `Release: MVP`, полями Priority, Size и Target date.
3. `Done` - список завершенных задач для отчета и демонстрации прогресса.

## Доступ

В проект добавляются Мурат Аяулым и преподаватель. Заказчик не обязан работать в GitHub: результаты показываются ему на короткой демонстрации.
