# Релизный план Pelargonium Shop

## Цель

Релизный процесс обеспечивает предсказуемое обновление проекта и позволяет быстро вернуться к последней стабильной версии при ошибке.

## Окно релиза

Плановое окно релиза: вторник или четверг с 18:00 до 20:00 по времени Астаны. В этот период команда доступна для проверки и отката. Релизы не проводятся в пятницу вечером, в праздничные дни и во время отсутствия ответственного.

## Ответственные

- Мурат Аяулым: PM, координация релиза, проверка чек-листа и решение об откате.
- Мурзаканов Еснур: функциональная проверка после публикации и фиксация результата.
- Владелец бизнеса: приемка каталога, формы заказа и информации для покупателей.

## Чек-лист релиза

- Состав изменений связан с задачами GitHub Project.
- GitHub Actions завершил линтер, тесты, сканирование и сборку без ошибок.
- Форма заказа, каталог и изменение наличия проверены на тестовом сценарии.
- Резервная копия данных создана.
- Инструкции и памятка по уходу актуальны.
- Ответственный за наблюдение после релиза назначен.
- План отката доступен команде.

## Критерии отката

Команда начинает откат, если форма заказа не сохраняет заявку, каталог недоступен, данные о наличии отображаются неверно или критическая проверка безопасности завершилась ошибкой.

## План отката

1. Остановить дальнейшее распространение версии.
2. Вернуть предыдущий стабильный артефакт или коммит.
3. Проверить каталог, форму заказа и административную часть.
4. При изменении данных восстановить проверенную резервную копию.
5. Сообщить заказчику о результате.
6. Создать задачу с причиной сбоя и действиями по исправлению.

## Наблюдение после релиза

В течение первого часа команда проверяет доступность основных страниц, отправку заказа и корректность данных о наличии. Результат фиксируется в GitHub.
