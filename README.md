# Pelargonium Shop

Учебный ИТ-проект: веб-система с каталогом сортовых пеларгоний и приемом заказов.

## Цель проекта

Собрать фотографии, названия, цены и актуальное наличие растений в одном каталоге. Заявки покупателей должны автоматически попадать в реестр и получать понятный статус.

## Заказчик

Владелец малого бизнеса по выращиванию и продаже сортовых пеларгоний. Заказчик уточняет требования и принимает результат.

## Модель поставки

Адаптивная модель с управлением потоком по Kanban. Обоснование решения находится в [ADR-001](docs/adr/ADR-001-delivery-model.md).
